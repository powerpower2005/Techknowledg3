# 가상화

## 가상화기능
1대의 물리 기기에서 여러 시스템을 가동함

머신에 가상머신을 여러 개 만들고, 각각의 가상 머신을 고객이 빌려쓰는 IaaS AWS에서는 EC2가 그 예

반대로 여러 대의 물리기기를 하나의 시스템으로 만드는 것도 가능함


## 가상화 소프트웨어
- KVM, Kernel-based Virtual Machine
- QEMU 
- virt-manager
