# 오픈소스 라이선스 기초

오픈소스라는 말만으로 수정·배포 조건이 모두 같지는 않다. 사용하는 소프트웨어의 정확한 라이선스와 파일별 copyright·notice를 확인한다.

## MIT와 GPL의 차이

MIT는 copyright와 허가 고지 유지 등의 조건으로 사용·수정·배포를 허용하는 permissive 라이선스다. 수정 결과를 반드시 같은 라이선스로 배포해야 한다는 공통 규칙은 아니다.

GPL의 copyleft 조건은 해당 저작물의 배포 방식과 파생물 관계에 따라 검토한다. 사적으로 사용·수정하기만 했다는 이유로 변경 소스를 공개해야 하는 것은 아니다. GPL과 AGPL은 네트워크를 통한 사용에 관한 조건도 같지 않다. 단순히 내부용인지 공개용인지 한 가지 기준만으로 모든 의무를 판단하지 않는다.

## 실제 확인 절차

dependency와 vendored 파일 목록, 라이선스 버전, 배포물에 포함되는 방식과 고지·소스 제공 요구를 확인한다. 이미지·문서·코드의 라이선스가 다를 수 있다. 다운로드가 가능하다는 사실은 재배포 허가와 같지 않다.


## 적용 범위와 확인

MIT 라이선스 원문과 GNU GPL FAQ의 사용·배포 구분 기준으로 설명했습니다. 기술 내용의 문서 검토일은 2026-10-06입니다. 예제를 실제 제품 환경에서 실행했다는 뜻은 아닙니다.
