# 기술 학습 자료

## 공식 문서로 시작하기

버전과 적용 환경을 함께 기록하며 개념 설명, API reference, 운영 안내를 구분해서 읽는다. 검색 결과의 코드가 현재 버전에 적용되는지도 확인한다.

- Kubernetes는 개념 → 작업 안내 → troubleshooting 순서로 읽고 개인 실습 클러스터에서 재현한다.
- Java는 사용 중인 JDK API와 migration/release 문서를 기준으로 동작을 확인한다.
- Redis는 명령의 반환값·시간 복잡도와 persistence·eviction 설정을 함께 본다.
- Linux는 배포판과 커널 버전을 기록하고 man page에서 옵션·권한·부작용을 확인한다.

## 읽은 내용을 노트로 남기기

문제, 관찰, 가설, 최소 재현, 결과, 한계를 적는다. 원문을 길게 복제하기보다 자신의 설명과 작은 예제를 쓰고 출처를 붙인다. 조직 내부 링크나 접근 권한이 필요한 자료는 일반 참고 목록에 섞지 않는다.

## 적용 범위와 확인

공개 공식 자료를 이용하는 학습 방법 기준으로 설명했습니다. 기술 내용의 문서 검토일은 2026-10-06입니다. 예제를 실제 제품 환경에서 실행했다는 뜻은 아닙니다.
